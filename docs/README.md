path under [`en/`](./en/) and [`pt-BR/`](./pt-BR/). English is canonical when the
two disagree.

caminho em [`en/`](./en/) e [`pt-BR/`](./pt-BR/). Quando as duas versões
divergem, vale a em inglês.
