# Créditos — Guardião da Cultura

Este arquivo espelha a tela de créditos do jogo
(`front/src/ui/credits/creditsData.ts`). Os dois são a mesma obrigação de
atribuição em dois formatos: um para quem joga, outro para quem reutiliza os
arquivos. Alterações precisam ser feitas nos dois, no mesmo pull request.

Os termos de uso de cada arquivo estão em [`ASSETS-LICENSE.md`](./ASSETS-LICENSE.md).
O código-fonte é MIT ([`LICENSE`](./LICENSE)); as marcas institucionais não são
licenciadas ([`NOTICE`](./NOTICE)).

> **Se você reutilizar qualquer arquivo de `front/public/assets/`, leve estes
> créditos junto.** Publicar apenas a licença MIT não cumpre a condição sob a
> qual as obras abaixo foram liberadas.
